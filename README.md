# Fulhambeer F7

Convocatorias, cervezas, MVP, multas y liga del Fulhambeer (Liga Municipal F7 Pozuelo · 3ª División Grupo A).

- Web estática (GitHub Pages): `index.html`
- Backend: Supabase (Postgres + RLS + realtime). Esquema en `supabase/schema.sql`, función admin en `supabase/functions/admin`.
- La clave publicable de Supabase va en el HTML a propósito: las escrituras están limitadas por RLS.
